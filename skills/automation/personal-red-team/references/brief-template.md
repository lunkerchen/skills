# 決策簡報模板

每份簡報 = 一個等待使用者判斷的決策。**一份只談一件事**。檔案命名：`brief-NN-主題.md`。

```markdown
---
type: decision-brief
date: YYYY-MM-DD
title: brief-NN 主題一句話
status: 待決策
---

# brief-NN — 主題

## 現況（證據）
- 具體事實 + 佐證（檔案路徑/時間戳/大小/log 行），不寫推測
- 若有多份證據，每條一行
- 標註「⚠️ 時序更新」如果審計期間狀態已變

## 風險 / 機會
- 不做的成本是什麼（具體：錢/資料/注意力/token）

## 選項
- **A. 方案名**（建議）：做了之後的影響（好處 + 代價 + 可逆性）
- **B. 方案名**：影響
- **C. 維持現狀**：不做的影響（有時 C 就是答案）

## 建議
一句話推薦 + 理由（證據優先）。

## 下一步（2 分鐘）
使用者回一個字母即可開工；或說明需要他提供什麼（密鑰/授權/確認）。
```

## 寫作規則

1. **選項用 A/B/C 字母**，使用者可以直接回「03A 06B」批次決策
2. 影響要寫「做了之後會怎樣」，不是重複描述選項
3. 標明每個選項的**可逆性**（可逆/需重建/不可逆）
4. 有卡點（需要使用者提供東西）要明寫在下一步
5. 十份以內：優先序分 🔴P1（現在決定）/ 🟠P2（快速贏）/ 🟡P3（低風險確認）

## 範例

```markdown
## 選項
- **A. 驗證遠端**（建議）：啟動 VPN → 遠端查詢。30 分鐘。若服務活著：確認無事；若死了：知道要修
- **B. 遷回本機**：本機常駐服務，不再依賴遠端；需移植 .env + plist，20 分鐘
- **C. 確認停用**：功能停止、更新記憶；零維護

## 下一步（2 分鐘）
回「A」— 我啟動 VPN 並驗證（唯讀查詢）。
```
