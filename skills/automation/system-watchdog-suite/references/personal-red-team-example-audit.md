# 實例：一次完整紅隊審計（通用化）

以下是 2026-08 一次真實審計的精簡記錄（個人細節已通用化）。展示：證據 → 發現 → 安全修復 → 決策 → 結果的完整閉環。

## 起點

使用者一句話：「成為我的個人紅隊。分析每個活躍專案、產品想法、工作流、週期性承諾。找弱假設、隱藏風險、浪費、該停止的事、系統性漏掉的機會。證據導向、不留情面。能安全改的直接改，需要判斷的做決策簡報。」

## 證據收集（~15 分鐘）

- 40 個 cron jobs（2 個 profile）
- 60+ 專案目錄（git 活動度 + 大小）
- 543 個 skills / 387MB
- launchd 服務 + LaunchAgents plist
- 跨 agent 共享記憶檔
- 磁碟 27GB dev 垃圾

## 發現（每項帶證據）

### 🔴 幽靈自動化（每天 12 次 LLM 呼叫打水漂）
**證據**：content profile 的 QA loop 每 2 小時執行，指向**已遷移到新路徑的舊專案目錄**；loop 狀態檔顯示 `{"phase": "done", "iteration": 4, "maxIterations": 3}` — 早就該停，卻持續跑了數週，當天 19:55 還在寫舊目錄。
**判定**：SAFE-FIX（暫停可逆；同專案另有 3 個維護 job 覆蓋）。
**動作**：暫停。每天省 12 次 LLM 呼叫。

### 🔴 五個 cron 死於同一 provider HTTP 500
**證據**：5 個 job 的 output 檔結尾全是 `RuntimeError: HTTP 500: Internal server error`；其中一個 27 次執行失敗 17 次（63%）；失敗史顯示間歇性（8/4 起）。同 provider 的其他 job 同時段成功 → 不是全域掛掉。
**機制**：config 有 fallback 但 cron jobs 在 jobs.json **顯式 pin provider** → fallback 永不啟動。
**判定**：NEEDS-DECISION（改路由影響品質/成本）。
**決策**：使用者選「接受並監控」→ 記錄觀察點，不改。

### 🟠 記憶 vs 實體不符（弱假設）
**證據**：跨 agent 記憶寫「服務用 launchd 雙 plist 在跑」→ 本機 LaunchAgents 查無 plist；專案 README 說部署在遠端機；遠端 VPN 停止、無法連線 → **死活無法驗證**。
**判定**：NEEDS-DECISION（涉及錢的風險）。
**決策**：使用者確認停用 → 更新記憶與共享檔。

### 🟠 生成 >> 發布
**證據**：每日內容管線 5 週只落地 7 篇草稿；發布追蹤檔停在 5 週前；產出的文案自註「發布前請人工確認」→ 全部堆積無發布機制。
**判定**：NEEDS-DECISION（改節奏 vs 建審核流程）。

### 🟠 冷庫與磁碟
**證據**：543 個 skills 中 cron 引用僅 1.2MB（99.7% cold）；備份快照 5 份無輪替（462MB）；node_modules 14GB、Rust target 5.4GB、單檔 log 873MB。
**判定**：冷庫歸檔 = NEEDS-DECISION；快照輪替 + dev 垃圾 = SAFE-FIX（使用者選了只清最大件）。

## 已修復（當場做，全部可逆）

| 動作 | 效果 |
|---|---|
| 暫停幽靈 QA loop | 每天 -12 LLM 呼叫 |
| 驗證 watchdog 自癒 | 錯誤狀態是歷史殘留，腳本已修（測試跑 = healthy） |
| 憑證掃描 | 確認 git 只追蹤 .env.example，無洩漏 |
| 備份輪替 5→2 份 | -276MB |
| 清 dev 垃圾（target/.next/node_modules/log 檔） | -12.5GB |
| 修正誤導記憶 | 後續 session 不再重複踩 |

## 決策簡報（10 份 → 使用者一次回覆）

回覆格式：「03C、06不做、02C、01A、05C、08C、10A+B」— 每份簡報的選項用字母，批次決策 30 秒完成。

## 執行後

- 更新報告的決策執行紀錄
- 同步記憶與跨 agent 共享檔（記憶每次寫入後同步）
- 設定觀察點：重啟 job 首跑、改路由首跑
- 把整個工作流存成 skill（就是本 skill）

## 關鍵教訓

1. **記憶是假設，實體是證據** — 每次審計都從對照開始
2. **同錯誤跨 job = 系統性問題**，不要逐個修
3. **「error」狀態可能是歷史殘留** — 手動跑一次驗證再判定
4. **子代理報告會截斷** — 完整版在 cache 目錄
5. **決策要能批次回覆**（字母編號），降低使用者的決策成本
