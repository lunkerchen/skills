# Stop Slop

消除預測性的 AI 寫作痕跡。在發布 Threads / vocus / 文案 / 腳本之前過一遍。

## 核心規則

1. **砍 filler**。去除清喉嚨開場、強調拐杖、所有副詞。見 reference。
2. **拆公式化結構**。避免二元對比、否定列表、戲劇化碎片、修辭鋪墊、假能動性。
3. **主動語態**。每個句子要有真人主詞在做事。沒有被動式。沒有無生命物體做人類動詞。
4. **具體**。沒有模糊陳述（「原因很結構性」）。指名具體事物。沒有懶惰極端詞（「每個人」、「永遠」、「從不」）。
5. **把讀者拉進現場**。沒有旁白者視角。「你」好過「人們」。具體好過抽象。
6. **變化節奏**。混用句長。兩項好過三項。段落結尾不重複。不用 em dash。
7. **信任讀者**。直接陳述事實。跳過軟化、辯解、牽手引導。
8. **砍金句**。如果讀起來像可以截圖的語錄，改掉。

## 快速檢查清單

- 任何副詞？砍。
- 任何被動式？找到主詞，放句首。
- 無生命物體做人類動詞（「決策浮現」）？指名是誰做的。
- 句子以 Wh- 開頭？重構。
- 「@這裡是@」清喉嚨？砍到重點。
- 「不是 X，是 Y」對比？直接講 Y。
- 連續三句等長？打破一句。
- 段落以短句結尾？變換。
- Em dash 出現？移除。
- 模糊陳述（「這意義重大」）？講具體的意義是什麼。
- 旁白者視角（「沒有人設計這個」）？把讀者放進去。
- Meta 提示（「接下來本文將...」）？刪掉。

## 評分標準

| 維度 | 問題 |
|------|------|
| 直接度 | 陳述還是宣告？ |
| 節奏 | 有變化還是機械？ |
| 信任 | 尊重讀者智商？ |
| 真實感 | 像人寫的？ |
| 密度 | 還有能砍的嗎？ |

每項 1-10 分，低於 35/50 需要重寫。

## 參考檔案

### 要砍的片語

**清喉嚨開場**
「這裡是@」、「殘酷的事實是」、「原來」、「真正的 X 是」、「讓我說清楚」、「老實說」

**強調拐杖**
「句號。」 / 「細品。」 / 「這很重要因為」 / 「別搞錯」 / 「這就是為什麼重要」

**商業術語**
導航（挑戰）→ 處理、拆解（分析）→ 解釋、擁抱（不舒服）→ 接受、格局 → 情況、顛覆性 → 重要……

**副詞（全部砍）**
really, just, literally, genuinely, honestly, simply, actually, deeply, truly, fundamentally, inherently, inevitably, interestingly, importantly, crucially

**填充片語**
「本質上」、「在當今的 X 中」、「值得一提的是」、「歸根結底」、「說到」、「在一個 X 的世界裡」、「幾乎形成 X」（幾乎形成資訊瀑布／完美風暴）、「這一+名詞」開場（這一密度／這一趨勢／這一動作）

**遞進結構**
「不僅 X，更 Y」 → 直接講 Y。同樣包含「不只...更」、「不但...還」。台灣繁中 AI 寫作最常見的句法之一

**宣告型動詞**
「凸顯一個事實」 / 「凸顯了」 → 「顯示」「意思是」；「預示著」 → 不加動詞，直接講結果；「標誌著」 → 「代表」「意思是」；「這正是」 → 直接陳述

**Meta 評論**
「提示：」、「劇情反轉：」、「但你已經知道了」、「但那是另一篇了」、「X 是功能不是 Bug」、「接下來本文將…」

### 要避免的結構

**二元對比**
「不是因為 X。是因為 Y。」 → 直接講 Y

**否定列表**
「不是 A… 不是 B… 是 C。」 → 直接講 C

**戲劇化碎片**
「[名詞]。就是這樣。」 → 完整句子

**修辭鋪墊**
「如果我告訴你…？」 → 直接陳述

**假能動性**
「投訴變成了修復」 → 某人修復了它

**旁白者距離**
「沒有人設計這個」 → 「你不會某天坐下來決定…」

**被動式**
「X 被創建」 → 誰創建了它

### 範例

**Before:**
> 「Here's the thing: building products is hard. Not because the technology is complex. Because people are complex. Let that sink in.」

**After:**
> 「Building products is hard. Technology is manageable. People aren't.」

**Before:**
> 「It turns out that most teams struggle with alignment. The uncomfortable truth is that nobody wants to admit they're confused.」

**After:**
> 「Teams struggle with alignment. Nobody admits confusion.」
