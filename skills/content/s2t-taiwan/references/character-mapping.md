## Taiwan vs Hong Kong Variant Differences

| Character | Taiwan | Hong Kong | Notes |
|---|---|---|---|
| inside | **裡** | 裏 | 這裡, 裡面 |
| relation | **係** | 係 | 關係 (same in both) |
| for/because | **為** | 爲 | 因為, 成為 |
| crowd | **眾** | 衆 | 聽眾, 觀眾 |
| group | **群** | 羣 | 社群, 群體 |
| peak | **峰** | 峯 | 高峰, 峰值 |
| start | **啟** | 啓 | 啟動, 啟用 |
| exit | **出** | 齣 | same character, HK uses 齣 for "a play" |
| trace | **蹤** | 踪 | 追蹤 |
| review | **覆盤** | 復盤 | Taiwan business usage |

## Key Terminology Decisions

| Term | Taiwan Form | Notes |
|---|---|---|
| number / digit | **數字** | DO NOT convert to 數位 when meaning number |
| digital | **數位** | Only use for "digital" (數位轉型, 數位科技) |
| data | **數據** | Keep as is; standard in Taiwan tech context |
| information | **資訊** | Replace 信息 → 資訊 |
| quality | **品質** | Replace 質量 → 品質 |
| optimize | **最佳化** | Replace 優化 → 最佳化 |
| user | **使用者** | Replace 用戶 → 使用者 |
| network | **網路** | Replace 網絡 → 網路 |
| internet | **網路** | Replace 互聯網 → 網路 |
| software | **軟體** | Replace 軟件 → 軟體 |
| project | **專案** | Replace 項目 → 專案 |
| feedback | **回饋** | Replace 反饋 → 回饋 |
