## 核心命題

市面 GEO 產品幾乎都是「監測型 SaaS」——告訴你提及率多少、排名第幾，按月收費，然後沒了。
GeoLook 涵蓋從 **現狀分析→診斷→方案→實施工單→執行落地→效果驗收** 全鏈路。

## 一、採樣紀律（數據真假的生命線）

GEO 的一切指標都來自【拿真實用戶會問的問題，逐個引擎採樣 AI 回答】。這一步不講紀律，後面全是假數：

1. **點名品牌的問題必須剔除** — 問「GeoLook 怎麼樣」，AI 當然會複述品牌名，提及率 100%，純假陽性。這類題單獨歸「品牌認知探測」，絕不混進可見性指標。
2. **別名漏配會系統性低估提及率** — AI 提你的簡稱、英文名、俗稱都算提及，別名表不全數據就偏低。
3. **中文題不打海外引擎，英文題不打國內引擎** — 問題庫按市場路由，國內海外分開出題、分開算指標，不合併平均。
4. **採樣量可以小，口徑必須硬。寧可顯示「未測」，不編數。**

## 二、15 個引擎接入實況

### 國內（走 API 自動採樣）
智譜 GLM、豆包（方舟）、DeepSeek、Kimi、MiniMax

### 國內（無公開 API，走人工採樣表）
納米 AI、百度 AI — 導出→瀏覽器逐題問→回灌，跟自動採樣進同一套指標

### 海外
Gemini、OpenAI、Claude、Grok、Perplexity

### 踩坑記錄
- **Claude 是原生 Messages 協議** — 大部分引擎是 OpenAI 兼容端點一套代碼通吃，Claude 響應結構完全不同，要單獨寫
- **豆包聯網需在火山控制台開通「內容插件」** — 不開通就靜默降級成不聯網採樣，你以為在測聯網表現，其實測的是參數化知識
- **Perplexity 是海外唯一原生返回 citations 的通道** — 引用來源數據質量最好

## 三、最反直覺的數據：官網只佔引用的 1.37%

基於 18.7 萬條國內 AI 引用語料的實算結果：

- **品牌官網類信源只佔全部引用的 1.37%**
- 官網是**事實源**不是**引用源** — 作用是讓 AI 描述你時口徑正確，但別指望它帶來引用量
- **28 個榜單站域名吃掉 9.1% 的全庫引用**，平均引用位置還是全庫最靠前的。AI 回答「有哪些/哪個好/怎麼選」時，最省事就是抄一份現成榜單
- **sm.cn（夸克）是全庫平均引用位置最靠前的域名**，也是千問約 19% 引用的來源 — 提交收錄幾乎零成本，但幾乎沒人做
- 百度 AI 和文心高度封閉在百度生態內，不進百科、百家號，基本進不了這兩個引擎

→ GeoLook 把 19 個陣地按真實引用數據標了權重和優先級，每個陣地寫清楚建什麼、建多少、什麼節奏、誰來做。

## 四、什麼樣的內容會被 AI 引用（實測數字）

基於 602 條 Prompt / 21,143 條引用：

| 內容特徵 | 被引用機率提升 |
|---|---|
| 含數字 | +61.6% |
| 含定義塊 | +57.3% |
| 含對比表 | +55.3% |
| 含操作步驟 | +41.2% |
| 純 Q&A 排版 | **-5.7%**（反直覺！） |

- 高影響力頁面平均 **1,943 詞**，低分頁僅 **170 詞**
- **對題性（r=0.432）是最強預測因子**，比權威度還高
- GeoLook 內容工作台把這些做成寫稿時的實時預檢，缺哪個塊、詞數夠不夠，邊寫邊亮燈

## 五、驗收即產品

每條工單都帶機器可判定的驗收標準（如「缺定義塊的頁面數下降 ≥ 50%」「目標域名出現在採樣引用中」）。
系統重抓站點 + 對比下期採樣，自動判通過/未達標，迴歸自動打回。

示例 21 條工單中 18 條（86%）完全不需要人工回填狀態。

核心判斷：**「建議」和「服務」的分界線就是能不能自動驗收。**

## 六、工程決策

- 依賴只有三個：requests / beautifulsoup4 / lxml，服務端 Python 標準庫 http.server，前端單檔 HTML。部署 = clone + pip install + 一條命令
- **數據即文件**：沒有資料庫，每個專案就是一個目錄下的 JSON 和 Markdown，git 一下就是備份
- **安全邊界寫死在程式碼裡**：金鑰只進本地 .env（權限 600）、服務只綁 127.0.0.1、發布永遠人工確認、公眾號/WordPress 只進草稿箱，沒有任何自動對外發布路徑
- **AI 參與但不放權**：LLM 只從官網正文抽取事實，抽不到標「待確認」，嚴禁用常識填充；AI 初稿必須過編造風險檢查 + 人工核實才能發布
